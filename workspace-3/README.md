# Life OS — Панель управления жизнью

Веб-приложение для контроля финансов, задач, целей и расписания в лёгкой RPG-упаковке.

## 🚀 Быстрый старт

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

## 📦 Сборка

```bash
npm run build
```

Результат в папке `dist/`.

## 🎮 Игровая механика

### Энергия (0–100)
- +8 за выполненную задачу (+12 за сложную)
- +5 бонус XP за выполнение раньше дедлайна
- −5 за просроченную задачу (макс −15/день)
- −10 за перерасход бюджета (1 раз/день)
- +25 за закрытую цель
- +5 за выполненный отдых
- **Не падает от бездействия** — приложение не наказывает за отдых

### XP и уровни
- +20 XP за задачу (+35 за сложную)
- +5 бонус за раннее выполнение
- +100 XP за закрытую цель
- Уровень = floor(XP / 200) + 1

### Свободные деньги
- `(месячный лимит − потрачено) / оставшиеся дни`
- Статусы: «В норме» / «Есть риск» / «Перерасход»

### Прогресс цели
- Финансовая: 60% деньги + 40% задачи
- Привычка/проект: 60% вехи + 40% задачи

## 🎨 Dynamic UI
Акцентный цвет интерфейса реагирует на состояние:
- 🟢 Изумруд — всё по плану
- 🟡 Янтарь — есть риск
- 🔴 Коралл — перерасход или много просрочек

## 📱 PWA
Приложение можно установить на iPhone/Android:
- Откройте в Safari/Chrome
- «Добавить на экран»
- Работает оффлайн с локальными данными

## 🗂 Структура

```
src/
├── config.ts              — игровые константы
├── types.ts               — TypeScript типы
├── store/
│   ├── useStore.ts        — Zustand store (persist в localStorage)
│   └── energyEngine.ts    — расчёт энергии, XP, свободных денег
├── components/
│   ├── ui/index.tsx       — GlassCard, ProgressBar, CircularProgress, Modal
│   └── Navigation.tsx     — нижняя навигация + сайдбар
├── screens/
│   ├── Onboarding.tsx     — 3-шаговый онбординг
│   ├── Dashboard.tsx      — главная с 4 плитками
│   ├── Finance.tsx        — финансы с графиками
│   ├── Tasks.tsx          — задачи/квесты
│   ├── Goals.tsx          — цели с вехами
│   ├── Schedule.tsx       — расписание (день/неделя)
│   └── Profile.tsx        — профиль, бейджи, настройки
└── App.tsx                — роутинг, layout
```

## ⚙️ Технологии

- React + TypeScript + Vite
- Tailwind CSS (v4)
- Framer Motion — анимации
- Zustand + persist — состояние
- date-fns — работа с датами
- Lucide React — иконки
- Recharts — графики

## 💾 Данные

Все данные хранятся локально в localStorage. В профиле доступны:
- Экспорт JSON
- Импорт JSON
- Сброс демо-данных
- Полная очистка
